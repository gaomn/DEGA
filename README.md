## 简介

MPDA： 多无人机多任务协调分配系统

## 特性

- 特性一：多任务
- 特性二：多无人机
- 特性三：多目标

## 安装与提交

提供安装该项目的步骤。以下是一个示例步骤：

1. 克隆该仓库：
   ```bash
   git clone https://github.com/gaomn/MPDA_GA.git
   ```
2. 进入项目目录：
   ```bash
   cd MPDA_GA
   ```
3. 添加远程仓库：
   ```bash
   git remote add origin https://github.com/gaomn/MPDA_GA.git
   ```
4. 提交更改：
   ```bash
   git add.
   git commit -m 'Add some foo'
   ```
5. 推送到远程仓库：
   ```bash
   git push origin master
   ```
